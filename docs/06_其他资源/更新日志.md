## 🔄 升级指南

### 从v1.1.0升级到v1.2.0

#### 1. 备份数据
```bash
# 备份数据库
./deploy.sh prod backup db

# 备份配置文件
cp -r deployment/environments deployment/environments.backup
```

#### 2. 更新代码
```bash
# 拉取最新代码
git pull origin main

# 检查配置文件变更
diff deployment/environments/.env.prod deployment/environments/.env.prod.example
```

#### 3. 更新环境配置
```bash
# 更新环境变量（如有新增）
vim deployment/environments/.env.prod

# 验证配置
./deploy.sh prod validate-config
```

#### 4. 执行升级
```bash
# 停止服务
./deploy.sh prod stop

# 重新构建镜像
./deploy.sh prod build

# 执行数据库迁移（如有）
./deploy.sh prod migrate

# 启动服务
./deploy.sh prod up

# 验证升级
./deploy.sh prod health
```

#### 5. 验证功能
- [ ] 用户登录功能正常
- [ ] 文件上传功能正常
- [ ] 数据库连接正常
- [ ] API接口响应正常
- [ ] 前端页面加载正常

### 从v1.0.0升级到v1.1.0

#### 数据库迁移
```sql
-- 添加新表和字段
ALTER TABLE users ADD COLUMN avatar VARCHAR(255);
ALTER TABLE users ADD COLUMN bio TEXT;

-- 创建新表
CREATE TABLE works (
  id VARCHAR(36) PRIMARY KEY,
  user_id VARCHAR(36) NOT NULL,
  title VARCHAR(255) NOT NULL,
  description TEXT,
  category ENUM('photo', 'video', 'audio') NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 配置更新
```bash
# 新增环境变量
echo "JWT_REFRESH_SECRET=your_refresh_secret" >> .env.prod
echo "UPLOAD_MAX_SIZE=10485760" >> .env.prod
```

## 🚧 已知问题

### 当前版本已知问题

#### 性能相关
- **大文件上传**：超过100MB的文件上传可能超时
  - **临时解决方案**：分片上传或使用CDN直传
  - **计划修复版本**：v1.3.0

- **数据库查询**：复杂查询在大数据量时性能下降
  - **临时解决方案**：添加适当索引，使用分页查询
  - **计划修复版本**：v1.2.1

#### 兼容性问题
- **IE浏览器**：不支持IE11及以下版本
  - **解决方案**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）

- **移动端适配**：部分页面在小屏幕设备上显示不完整
  - **临时解决方案**：使用横屏模式
  - **计划修复版本**：v1.2.1

#### 功能限制
- **批量操作**：暂不支持批量删除和批量编辑
  - **计划添加版本**：v1.3.0

- **实时通知**：暂不支持实时消息推送
  - **计划添加版本**：v1.4.0
