## ❓ 常见问题解答 (FAQ)

### 🚀 部署相关问题

#### Q1: Docker容器启动失败怎么办？
**A:** 按以下步骤排查：

1. **检查Docker服务状态**
```bash
sudo systemctl status docker
sudo systemctl start docker  # 如果未启动
```

2. **查看容器日志**
```bash
docker logs container_name
```

3. **检查端口占用**
```bash
netstat -tlnp | grep :端口号
```

4. **检查磁盘空间**
```bash
df -h
docker system df
```

5. **清理Docker资源**
```bash
docker system prune -a
```

#### Q2: 数据库连接失败如何解决？
**A:** 常见解决方案：

1. **检查数据库服务状态**
```bash
docker ps | grep mysql
docker logs wedding-mysql-prod
```

2. **验证数据库连接**
```bash
docker exec wedding-mysql-prod mysql -u root -p -e "SELECT 1"
```

3. **检查网络连接**
```bash
docker network ls
docker network inspect wedding-network
```

4. **重置数据库密码**
```bash
docker exec wedding-mysql-prod mysql -u root -p -e "ALTER USER 'root'@'%' IDENTIFIED BY 'new_password';"
```

#### Q3: 前端页面无法访问怎么办？

1. **检查Nginx服务**

2. **检查前端构建**

### 🔐 认证相关问题

#### Q7: JWT Token过期如何处理？
**A:** 自动刷新机制：

```javascript
// 前端Token刷新逻辑
const refreshToken = async () => {
  try {
    const response = await fetch('/api/v1/auth/refresh', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        refreshToken: localStorage.getItem('refreshToken')
      })
    });
    
    if (response.ok) {
      const data = await response.json();
      localStorage.setItem('accessToken', data.accessToken);
      return data.accessToken;
    }
  } catch (error) {
    // 跳转到登录页
    window.location.href = '/login';
  }
};

// Axios拦截器
axios.interceptors.response.use(
  response => response,
  async error => {
    if (error.response?.status === 401) {
      const newToken = await refreshToken();
      if (newToken) {
        error.config.headers.Authorization = `Bearer ${newToken}`;
        return axios.request(error.config);
      }
    }
    return Promise.reject(error);
  }
);
```

#### Q8: 用户权限验证失败怎么办？
**A:** 权限问题排查：

1. **检查用户角色**
```sql
SELECT id, username, role, status FROM users WHERE id = 'user_id';
```

2. **验证权限配置**
```javascript
// 后端权限检查
const checkPermission = (userRole, requiredPermission) => {
  const rolePermissions = {
    'super_admin': ['*'],
    'admin': ['user:read', 'user:write', 'content:*'],
    'member': ['profile:read', 'profile:write', 'schedule:*']
  };
  
  const permissions = rolePermissions[userRole] || [];
  return permissions.includes('*') || 
         permissions.includes(requiredPermission) ||
         permissions.some(p => p.endsWith('*') && requiredPermission.startsWith(p.slice(0, -1)));
};
```

3. **清除权限缓存**
```bash
# Redis清除用户权限缓存
docker exec wedding-redis-prod redis-cli DEL "user:permissions:user_id"
```

#### Q12: 数据库查询慢如何优化？
**A:** 数据库优化方案：

1. **添加索引**
```sql
-- 分析慢查询
EXPLAIN SELECT * FROM users WHERE email = 'user@example.com';

-- 创建索引
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_schedules_date_status ON schedules(date, status);
```

2. **查询优化**
```sql
-- 避免SELECT *
SELECT id, username, email FROM users WHERE status = 'active';

-- 使用LIMIT
SELECT * FROM schedules ORDER BY date DESC LIMIT 20;

-- 使用JOIN替代子查询
SELECT u.username, s.date 
FROM users u 
JOIN schedules s ON u.id = s.user_id 
WHERE s.status = 'available';
```

3. **连接池优化**
```javascript
// 数据库连接池配置
const pool = mysql.createPool({
  host: process.env.DB_HOST,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
  connectionLimit: 20,
  acquireTimeout: 60000,
  timeout: 60000
});
```

#### Q13: 如何防止SQL注入攻击？
**A:** 安全防护措施：

1. **使用参数化查询**
```javascript

const user = await db.query('SELECT * FROM users WHERE id = ?', [userId]);

// 错误方式（容易被注入）
const user = await db.query(`SELECT * FROM users WHERE id = ${userId}`);
```

2. **输入验证**
```javascript
const Joi = require('joi');

const userSchema = Joi.object({
  email: Joi.string().email().required(),
  password: Joi.string().min(8).required()
});

const { error, value } = userSchema.validate(req.body);
if (error) {
  return res.status(400).json({ error: error.details[0].message });
}
```

3. **权限控制**
```javascript
const requireAuth = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) {
    return res.status(401).json({ error: '未授权访问' });
  }
  
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (error) {
    return res.status(401).json({ error: 'Token无效' });
  }
};
```

```javascript
const LazyImage = ({ src, alt }) => {
  const [loaded, setLoaded] = useState(false);
  const imgRef = useRef();

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setLoaded(true);
          observer.disconnect();
        }
      },

    </div>
  );
```
