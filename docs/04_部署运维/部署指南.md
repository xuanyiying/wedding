# 婚礼主持俱乐部官方网站 - 部署指南

## 🚀 部署概述

### 部署目标
- **快速部署**：一键部署，快速上线
- **环境隔离**：开发、测试、生产环境完全隔离
- **高可用性**：支持负载均衡和故障转移
- **易于维护**：标准化部署流程，便于运维管理

### 部署架构
- **容器化部署**：使用Docker容器化所有服务
- **编排管理**：使用Docker Compose进行服务编排
- **环境配置**：通过环境变量管理不同环境配置
- **数据持久化**：重要数据使用数据卷持久化存储

## 📋 环境要求

### 系统要求
- **操作系统**：Ubuntu 20.04+ / CentOS 8+ / macOS 10.15+
- **CPU**：2核心以上
- **内存**：4GB以上
- **存储**：20GB以上可用空间

## 🔧 详细部署步骤

### 步骤1：环境准备

#### 安装Docker
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# CentOS/RHEL
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo yum install -y docker-ce docker-ce-cli containerd.io
sudo systemctl start docker
sudo systemctl enable docker

# macOS
brew install docker
```

#### 安装Docker Compose
```bash
# Linux
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# macOS (通过Homebrew)
brew install docker-compose
```

### 步骤2：项目配置

#### 目录结构
```
wedding-client/
├── deployment/
│   ├── environments/          # 环境配置文件
│   │   ├── .env.dev
│   │   ├── .env.test
│   │   └── .env.prod
│   ├── docker/               # Docker配置
│   │   ├── nginx/
│   │   ├── mysql/
│   │   └── redis/
│   ├── scripts/              # 部署脚本
│   └── ssl/                  # SSL证书
├── server/                   # 后端代码
├── web/                      # 前端代码
├── docker-compose.yml        # Docker编排文件
└── deploy.sh                 # 部署脚本
```

#### 环境变量配置
```bash
# deployment/environments/.env.prod
# =============================================================================
# 生产环境配置
# =============================================================================

# 环境标识
ENVIRONMENT=prod
NODE_ENV=production

# 应用配置
APP_NAME="婚礼主持俱乐部"
APP_URL=https://your-domain.com
APP_PORT=3000

# 数据库配置
DB_HOST=wedding-service-mysql-prod
DB_PORT=3306
DB_NAME=wedding_service_prod
DB_USER=wedding_service
DB_PASSWORD=wedding_service@2025!

# Redis配置
REDIS_HOST=wedding-service-redis-prod
REDIS_PORT=6379
REDIS_PASSWORD=your_redis_password

# JWT配置
JWT_SECRET=your_jwt_secret_key
JWT_REFRESH_SECRET=your_jwt_refresh_secret

# 文件存储配置
OSS_REGION=oss-cn-hangzhou
OSS_BUCKET=wedding-prod
OSS_ACCESS_KEY_ID=your_access_key
OSS_ACCESS_KEY_SECRET=your_access_secret

# 邮件配置
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=noreply@your-domain.com
SMTP_PASS=your_email_password

# 监控配置
SENTRY_DSN=your_sentry_dsn
LOG_LEVEL=info

# 端口配置
WEB_PORT=80
API_PORT=3000
MYSQL_PORT=3306
REDIS_PORT=6379
NGINX_PORT=80
```

### 步骤3：SSL证书配置

#### 获取SSL证书
```bash
# 使用Let's Encrypt免费证书
sudo apt install certbot
sudo certbot certonly --standalone -d your-domain.com

# 复制证书到项目目录
sudo cp /etc/letsencrypt/live/your-domain.com/fullchain.pem deployment/ssl/
sudo cp /etc/letsencrypt/live/your-domain.com/privkey.pem deployment/ssl/
sudo chown $USER:$USER deployment/ssl/*.pem
```

#### 证书自动续期
```bash
# 添加定时任务
sudo crontab -e

# 每月1号凌晨2点检查证书续期
0 2 1 * * /usr/bin/certbot renew --quiet && docker exec wedding-nginx-prod nginx -s reload
```

### 步骤4：数据库初始化

#### 数据库准备
```bash
# 启动数据库服务
./deploy.sh prod start mysql

# 等待数据库启动
sleep 30

# 执行数据库初始化
./deploy.sh prod init-db

# 验证数据库
docker exec wedding-mysql-prod mysql -u root -p -e "SHOW DATABASES;"
```

#### 数据迁移
```bash
# 执行数据库迁移
docker exec wedding-api-prod npm run migrate

# 执行数据填充
docker exec wedding-api-prod npm run seed

# 创建管理员账户
docker exec wedding-api-prod npm run create-admin
```

### 步骤5：服务部署

#### 构建镜像
```bash
# 构建所有服务镜像
./deploy.sh prod build

# 或者单独构建
docker build -t wedding-web:prod-latest ./web
docker build -t wedding-api:prod-latest ./server
```

#### 启动服务
```bash
# 启动所有服务
./deploy.sh prod up

# 或者分步启动
./deploy.sh prod start mysql redis    # 先启动基础服务
sleep 30
./deploy.sh prod start api           # 启动API服务
sleep 10
./deploy.sh prod start web nginx     # 启动前端和代理服务
```

#### 服务验证
```bash
# 检查服务状态
./deploy.sh prod status

# 检查服务健康
./deploy.sh prod health

# 查看服务日志
./deploy.sh prod logs api
./deploy.sh prod logs web
./deploy.sh prod logs nginx
```
