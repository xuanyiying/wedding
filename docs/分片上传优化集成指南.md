# 分片上传功能优化集成指南

## 概述

本文档详细说明了如何将优化的分片上传功能集成到现有的婚礼客户端项目中，在保持UI界面不变的前提下，显著提升文件上传性能和用户体验。

## 优化特性

### 1. 动态分片大小调整算法
- **智能分片大小计算**：根据文件大小、网络状态和历史性能数据动态调整分片大小
- **分片大小范围**：1MB - 20MB，默认5MB
- **自适应策略**：
  - 小文件（<50MB）：使用1MB分片
  - 大文件（>500MB）：使用20MB分片
  - 快速网络：增大分片大小
  - 慢速网络：减小分片大小

### 2. 智能并行上传控制机制
- **动态并发数调整**：根据网络状态、系统负载和错误率自动调整并发数
- **并发数范围**：1-6个并发连接，默认3个
- **负载均衡**：避免过度占用网络带宽和系统资源

### 3. 精确进度计算方案
- **实时速度监控**：计算每个分片的上传速度
- **平滑进度显示**：使用移动平均算法平滑进度变化
- **剩余时间估算**：基于当前速度预测剩余上传时间
- **网络状态感知**：实时检测网络状态变化

### 4. 智能重试和错误恢复
- **指数退避重试**：失败后使用指数退避算法重试
- **最大重试次数**：每个分片最多重试5次
- **错误分类处理**：区分网络错误、服务器错误和用户取消
- **断点续传支持**：支持暂停和恢复上传

### 5. 网络状态感知和自适应
- **网络状态检测**：自动检测快速、正常、慢速网络状态
- **参数动态调整**：根据网络状态实时调整上传参数
- **性能监控**：持续监控上传性能并优化策略

## 集成步骤

### 步骤1：导入优化组件

在需要使用文件上传的组件中导入上传适配器：

```typescript
import { uploadAdapter, UploadMode } from './UploadAdapter';
import type { UploadProgress, UploadCallbacks } from './UploadAdapter';
```

### 步骤2：配置上传适配器

```typescript
// 配置上传适配器
uploadAdapter.updateConfig({
  mode: UploadMode.OPTIMIZED,        // 使用优化模式
  enableAutoSwitch: true,            // 启用自动切换
  fallbackOnError: true,             // 错误时回退到原有模式
  performanceThreshold: {
    minSpeed: 500 * 1024,            // 最小速度阈值 500KB/s
    maxErrorRate: 0.3                // 最大错误率 30%
  }
});
```

### 步骤3：使用优化的上传功能

```typescript
const handleFileUpload = async (file: File, category: string) => {
  const callbacks: UploadCallbacks = {
    onProgress: (progress: UploadProgress) => {
      console.log(`上传进度: ${progress.percentage}%`);
      console.log(`上传速度: ${(progress.speed! / 1024 / 1024).toFixed(2)} MB/s`);
      console.log(`剩余时间: ${progress.estimatedTime}秒`);
      console.log(`网络状态: ${progress.networkStatus}`);
      
      // 更新UI进度条
      setUploadProgress(progress.percentage);
      setUploadSpeed(progress.speed);
      setEstimatedTime(progress.estimatedTime);
    },
    
    onSuccess: (result) => {
      console.log('上传成功:', result);
      // 处理上传成功逻辑
    },
    
    onError: (error) => {
      console.error('上传失败:', error);
      // 处理上传失败逻辑
    }
  };

  try {
    const result = await uploadAdapter.uploadFile(file, category, callbacks);
    return result;
  } catch (error) {
    console.error('文件上传失败:', error);
    throw error;
  }
};
```

### 步骤4：集成到现有MediaUploaderCore

修改`MediaUploaderCore.ts`中的上传逻辑：

## 性能优化建议

### 1. 网络环境优化
- **快速网络**：使用大分片（10-20MB）和高并发（4-6个）
- **慢速网络**：使用小分片（1-2MB）和低并发（1-2个）
- **不稳定网络**：启用自动重试和错误恢复

### 2. 服务器配置优化
- **增加上传超时时间**：根据分片大小调整超时设置
- **优化并发处理**：服务器端支持多个并发分片上传
- **内存管理**：使用内存存储处理分片数据

### 3. 客户端优化
- **内存使用**：大文件分片时注意内存占用
- **用户体验**：提供详细的进度信息和网络状态显示
- **错误处理**：友好的错误提示和重试机制

## 故障排除

### 1. 常见问题

**问题：上传速度慢**
- 检查网络状态检测是否正确
- 调整分片大小和并发数
- 检查服务器端处理能力

**问题：上传失败率高**
- 检查网络稳定性
- 增加重试次数和延迟
- 检查服务器端错误日志

**问题：内存占用过高**
- 减小分片大小
- 降低并发数
- 检查内存泄漏

### 2. 调试步骤

1. 启用详细日志输出
2. 监控网络状态变化
3. 检查分片上传成功率
4. 分析性能统计数据
