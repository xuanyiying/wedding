## 🔧 常用命令

### 部署相关
```bash
# 完整部署
./deploy.sh deploy

# 启动服务
./deploy.sh start

# 停止服务
./deploy.sh stop

# 查看状态
./deploy.sh status

# 系统诊断
./deploy.sh diagnose
```

### 开发相关
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 运行测试
npm run test
```

### Docker相关
```bash
# 构建镜像
docker-compose build

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
